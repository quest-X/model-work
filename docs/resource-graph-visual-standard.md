# Model Work Node 资源 Graph 视觉分类标准

本标准用于计算群资源 Graph。视觉通道各自只表达一种信息，避免用同一符号同时表示实体类别和运行状态。

## 1. 形状：表达实体类别

| 形状 | 实体类型 | 说明 |
| --- | --- | --- |
| 圆形 | 计算群、计算节点 | 表达可以承载或组织计算工作的拓扑主体。计算群使用更大的圆形，计算节点使用标准圆形。 |
| 圆角矩形 | 计算资源、Work Agent、网络依赖、托管设备 | 表达依附于节点或计算群的能力、资源、链路与设备。摄像头属于托管设备，必须使用矩形。 |

以后新增实体时，只有具备独立计算节点身份的机器才使用圆形；摄像头、传感器、存储、GPU 资源、网络链路和软件 Agent 均使用矩形。

## 2. 颜色：表达运行状态

| 颜色 | 含义 | 使用规则 |
| --- | --- | --- |
| 绿色 | 在线、健康、当前可用 | 节点在线或实体当前可调用。 |
| 红色 | 离线、故障、当前不可用 | 使用纯红色实线边框和红色状态点，不使用红色虚线。 |
| 紫色 | 中性拓扑与身份 | 计算群、尚未强调状态的关系和通用实体。 |
| 蓝色 | 计算资源 | CPU、内存、GPU、存储等资源实体。 |
| 琥珀色 | 托管设备 | 摄像头、传感器等外部设备。 |

状态必须同时提供文字标签，颜色不能作为唯一的信息来源。

## 3. 线型：表达关系状态

| 线型 | 含义 |
| --- | --- |
| 实线 | 当前有效的包含、提供、执行、依赖或管理关系。 |
| 虚线 | 实体仍在台账中，但该关系当前不可用。虚线只用于连线，不用于实体边框。 |

关系颜色继续区分包含、提供/执行、依赖/管理；点击实体时，仅高亮其上下游关系。

## 4. 交互与可访问性

- 每个实体都必须暴露实体类型、形状和状态数据属性，供自动化测试和后续图谱工具读取。
- 在线/离线状态必须同时显示状态点、状态文字和最近心跳。
- 设备名称、型号与通道数显示在矩形实体中；详细信息通过点击实体查看。
- 点击图谱空白处取消聚焦，不改变图谱布局。
